# bench/cases

Inputs for the direct-API microbenchmarks (`bench/direct.mjs`, `bench/sweep.mjs`), generated by `bench/make-*-cases.mjs`.

Some files (`copy.json`, `short2.json`, `args.json`, `think.json`) embed tool results that were captured from live storefront searches on 2026-11-22, so that the benchmark requests look like the real run's requests. They are research inputs only. The plugin, the agents and the OpenClaw run never read this folder.
